# v0.1 — Skill, docs, and first release benchmark

`v0.1` is the first release that packages MALA as a usable public repository rather than only a set of essays.

## What is included

- onboarding-first `README.md` and `README.en.md`
- stable bilingual skill entry points
- the first frozen release-eval set built from 12 real public user prompts
- a depth-stratified benchmark split into `deep` (5), `medium` (5), and `negative_control` (2)
- official protocol, rubric, raw run artifacts, judgments, merged results, and summary pages
- an end-to-end release-eval workflow that turns official artifacts into refreshed results and case pages
- benchmark-backed case pages derived from that evaluation set

## Evaluation snapshot

- All 12 prompts in the release set have collected baseline and treatment runs plus judgments.
- In the current summary, treatment scored 6 or higher on all 5 `deep` prompts, all 5 `medium` prompts, and 1 of 2 `negative_control` prompts.
- The main reading rule is intentional: `deep` is the headline bucket, `medium` is supporting evidence, and `negative_control` marks where MALA should not be forced.
- Baseline and treatment are not scored on the same scale: baseline uses a compact `0-4` direct-answer score, while treatment uses a structural `0-8` score that includes diagnosis, repair, answer discipline, and intervention fit.

## What this version claims

- MALA is a problem-formulation skill for turning vague requests into answerable questions.
- In under-specified prompts, MALA can make diagnosis, repaired scope, and answer discipline explicit before answering.
- The benchmark in this release is designed to show formulation gain under a fixed protocol, not generic model superiority or a single-number leaderboard win.

## What this version does not claim

- It is not evidence that MALA should be applied to every prompt.
- It is not a universal reasoning booster.
- It does not guarantee that the final answer is correct.
- It is not a paper-level benchmark or a claim of statistical significance.

## Intended users

- LLM and agent users
- workflow designers
- researchers and builders working with under-specified tasks

## Next step

Later versions can expand the benchmark, add more cases, and turn MALA into more tool-specific integrations. `v0.1` keeps the scope narrow: clear positioning, a stable skill, and a frozen public evaluation set.
