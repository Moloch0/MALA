# 问题、回答与可求解结构

这组文章围绕一个主线展开：

> 回答是在既定问题中给出结果，提问则是在构造问题本身的可求解结构。

整个系列按“现象 -> 方法 -> 算法 -> 数学 -> 元问题”的顺序推进。

## 全系列核心命题

- 提问和回答不是同一种认知活动。
- 一个问题的质量，决定了一个回答的上限。
- 好问题不是一句带问号的话，而是一个可求解结构。
- 从算法角度看，提问是在组织搜索，回答是在压缩结果。
- 从 MDP 角度看，好问题等价于好的状态抽象。
- 对固定控制问题，好问题的数学标准是：最小充分、对控制闭合。
- 对跨环境鲁棒问题，还必须额外要求因果稳定。
