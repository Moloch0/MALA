# 什么叫一个好问题？

“提问很重要”这句话当然是对的，但如果只停在这里，它几乎什么也没有说。真正需要推进的是另一层：什么样的问题，才算好问题？

首先要排除几个很常见的误解。好问题不等于宏大，不等于新奇，不等于抽象，也不等于让人无从作答。一个问题可以非常小，却依然是好问题；也可以非常宏大，却只是修辞性的空话。问题的价值，并不取决于它听起来有多深，而取决于它是否真的把未知组织成了可推进的结构。

因此，一个好问题首先不是一句“很像问题的话”，而是一个被约束过的未知量。

它至少应当包含几个基本要素：它在问什么对象，缺失的到底是哪一个量，已知条件有哪些，哪些变化被排除，允许通过什么方式推进，以及什么算作答对。只有这些东西被明确到一定程度，问题才不再只是一个讨论话题，而开始具有求解意义。

从这个角度看，一个好问题至少有五个特征。

第一，它能区分不同答案。也就是说，不同回答之间必须真正有差别，而不是无论怎么说都可以勉强算对。如果一个问题容纳一切答案，它就等于没有提出任何要求。

第二，它能排除无关自由度。好问题不会让任何方向都同样合理，而是会删掉大量不相干的变化，把注意力逼向真正关键的缺口。它不是把空间打开，而是把空间收紧。

第三，它能暴露真正缺失的变量。很多时候我们以为自己“不知道很多东西”，其实更准确的说法是：我们不知道哪一块最值得知道。好问题的作用，不是展示无知的广度，而是定位无知的瓶颈。

第四，它能导向推进。也就是说，它应当让后续的分解、验证、递归、反证、比较或实验设计成为可能。一个问题如果无法引出任何后续操作，那么它至多是感叹，不是问题。

第五，它允许答案回代。一个回答出来之后，应该能够重新填回这个问题，而不是只在附近制造一种“似乎已经解释了”的效果。如果不能回代，就说明问题和回答之间并没有真正接上。

反过来说，坏问题通常也有几种典型形式。有的问题太散，什么都能谈，所以什么都谈不清；有的问题太空，没有判准，因此只能引发态度表达；有的问题太混，把几个不同层次的问题捆成一句话，看似深刻，实则无法推进；还有的问题只是语法上像问题，认知上却根本没有建立起未知与约束的关系。

因此，一个可工作的定义是：

> 好问题是在给定目标下，用最少但足够的结构，把真正未知暴露成一个可以推进的缺口。

这一定义里，“最少”意味着不能把无关信息也一并保留；“足够”意味着又不能把真正影响求解的结构删掉；“可推进”意味着问题必须能驱动后续操作，而不只是制造宏大感。

这样一来，我们就能更清楚地看见：问题的价值不在于它多么像一个哲学句子，而在于它是否有效地压缩了自由度。一个好问题不是问得大，而是切得准。它不是把未知神秘化，而是把未知定位出来。

如果这个理解成立，那么下一步就必须继续追问：所谓“可推进”究竟意味着什么？一个问题要推进到什么程度，才算真正具有求解结构？这时，提问就不再只是语言行为，而开始接近一种算法性的组织方式。
