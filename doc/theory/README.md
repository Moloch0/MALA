# Theory Track

This directory rebuilds the theoretical foundation of MALA-Graph from literature and first principles.

The current rule is conservative:

- do not treat the former eight-element interface as the ontology of a problem;
- first define what a problem is at the semantic, operational, and structural levels;
- only then derive any engineering interface that an LLM or solver should read.

## Literature Grounding

- [literature/01-ai-cognitive-problem-solving.md](literature/01-ai-cognitive-problem-solving.md): Newell & Simon, AIMA, state-space search, classical planning.
- [literature/02-inquiry-pragmatism.md](literature/02-inquiry-pragmatism.md): Peirce, Dewey, Collingwood, inquiry and problematic situations.
