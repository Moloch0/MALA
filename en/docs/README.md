# English Docs Index

This set of essays revolves around one central claim:

> Answers are given inside an already specified problem space, while questioning constructs the solvable structure of the problem itself.

If you are entering this repository for the first time, start from `00-overview` and then continue in numerical order.

## Main Essays

1. [00-overview](00-overview.md)  
   Series overview, structure, and suggested reading order.
2. [01-what-are-we-doing-when-we-ask](01-what-are-we-doing-when-we-ask.md)  
   Distinguishes questioning from answering as two cognitive activities.
3. [02-what-is-an-answer](02-what-is-an-answer.md)  
   Analyzes answers as compressed results: their structure, power, and limits.
4. [03-what-makes-a-good-question](03-what-makes-a-good-question.md)  
   Gives the basic criteria for a good question.
5. [04-questioning-as-an-algorithm](04-questioning-as-an-algorithm.md)  
   Understands questioning as search, decomposition, and recursion.
6. [05-from-question-to-mdp](05-from-question-to-mdp.md)  
   Compresses problem formulation into the framework of decision processes.
7. [06-the-mathematical-criterion-for-a-good-question](06-the-mathematical-criterion-for-a-good-question.md)  
   Gives the strict definition of minimal sufficiency and closure under control.
8. [07-causal-stability-and-cross-environment-robustness](07-causal-stability-and-cross-environment-robustness.md)  
   Explains why cross-environment tasks require causal stability on top.
9. [08-problem-of-problem](08-problem-of-problem.md)  
   Discusses the correctness conditions of problem construction itself.
10. [09-more-ask-less-answer-how-should-we-use-llms](09-more-ask-less-answer-how-should-we-use-llms.md)  
    Places the whole argument back into the use of LLMs.

## Appendices

1. [appendix-11-dimensions-and-pseudo-problems](appendix-11-dimensions-and-pseudo-problems.md)  
   Uses theoretical physics to show the difference between a grand interrogative and a researchable problem.
2. [appendix-problem-formulation-in-the-age-of-ai](appendix-problem-formulation-in-the-age-of-ai.md)  
   Explains why problem formulation becomes scarcer when answers become cheap.
