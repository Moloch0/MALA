# 什么是问题

## 结论

一个问题，不只是一个疑问句，也不只是一个困难、缺口或待办事项。更严格地说，问题是某个主体或主体群在特定情境中，把一个具有意义的未定性表征为需要回答、判断、行动或改变的对象。

因此，构成一个问题的最小充分必要条件可以压缩为四项：

1. **情境域**：问题必须发生在某个可能性空间、任务环境、实践处境或社会情境中。没有情境，就没有“什么算相关”“什么算改变”“什么算解决”的边界。
2. **未定性**：该情境中必须存在尚未确定、尚未区分、尚未满足或尚未选择的东西。它可以是未知答案、当前状态与目标状态的差距、行动受阻、价值冲突、解释竞争或方案不确定。
3. **关切与取向**：这种未定性必须对某个主体有认知、实践、价值或规范意义，并指向回答、判断、行动、安顿或改变。没有关切，只有差异；没有取向，只有混乱。
4. **解决判据**：必须有某种方式区分“问题被解决 / 部分解决 / 没有解决”。这个判据可以是目标测试、答案条件、证据标准、可继续行动的情境、可接受的方案、或在劣构情境中暂时形成的评价依据。

用一句话说：

```text
问题 = 在某个情境域中，被主体关切并指向解决的未定性。
```

更形式化地说：

```text
Problem = <C, U, A, R>
```

其中：

| 符号 | 含义 |
|---|---|
| `C` | context / field：情境域、可能性空间、任务环境或实践处境 |
| `U` | uncertainty / gap / issue：未定性、差距、疑惑、冲突或待决事项 |
| `A` | agent / concern / orientation：主体、关切、目的、需要或行动取向 |
| `R` | resolution condition：回答、解决、成功、可接受或可继续行动的判据 |

这四项共同构成“问题”的最小充分必要条件：缺少任何一项，都不足以构成问题；四项同时具备，就足以构成一个问题。不同理论传统的差别，主要在于它们如何解释这四项，以及把哪一项放在中心。

## 1. 问题不是疑问句

疑问句只是问题的一种表达形式，不是问题本身。

“今天会下雨吗？”这个句子可以表达一个问题，但只有在某个情境中，它才真正成为问题：例如有人要决定是否带伞、是否延期施工、是否启动防汛预案。若没有任何关切、行动差异或回答需求，它只是一个语法上可问的句子。

形式语义和问题逻辑传统尤其清楚地区分三件事：

| 层次 | 含义 |
|---|---|
| 问题句 | 自然语言中的疑问句，或形式语言中的问题表达式 |
| 问题 | 由答案、可能性划分或解决条件构成的语义对象 |
| 提问行为 | 某个说话人在特定语境中请求回答、推进议题或改变共同信息状态的行动 |

所以，“什么是问题”的核心不在问号，而在：什么算作回答，什么信息状态算作解决，以及这个回答为什么值得被寻求。

## 2. 问题不是单纯困难

困难、麻烦、障碍、痛苦、冲突都可能引发问题，但它们本身还不是问题。

例如，电脑突然变慢是一个困扰；它成为问题，需要进一步被表征为“是什么进程占用了资源”“系统是否感染恶意软件”“是否需要升级硬件”“怎样在不丢数据的情况下恢复性能”。同一个困扰可以被问题化为不同问题。

这说明问题不是原始给定物，而是对未定情境的组织。一个情境只有在被框定为“哪里未定、什么相关、如何判断、要往哪里改变”之后，才成为可处理的问题。

Dewey 的 inquiry 传统对此说得最直接：未定情境先于明确问题；问题是探究对未定情境的第一步规定。一个问题被好好提出，已经开始限制相关事实、候选假设和可能解法。

## 3. 问题的四个最小构件

### 3.1 情境域

问题总是在某个域中发生。

在经典 AI 中，这个域是状态空间：一组可能状态、可执行行动和状态转移。在问题逻辑中，这个域是可能世界空间或信息状态空间。在实用主义认识论中，这个域是行动者已经卷入的未定情境。在劣构和棘手问题传统中，这个域是组织、设计、政策或社会实践情境。

没有情境域，就无法判断一个差异是否相关。例如“温度是 30 度”本身不是问题；它在农业、芯片散热、人体舒适、化学实验或气候政策中，分别可能构成完全不同的问题。

情境域至少提供三类边界：

| 边界 | 作用 |
|---|---|
| 相关对象 | 哪些事实、变量、主体、材料或条件进入考虑 |
| 可能变化 | 哪些行动、操作、回答或解释是可考虑的 |
| 判断背景 | 什么算成功、失败、充分、可接受或更好 |

在良构问题中，情境域可以预先明确给出；在劣构问题中，情境域本身会成为争议对象。

### 3.2 未定性

问题必须包含某种未定性。没有未定性，就没有问题。

未定性有多种形式：

| 未定性类型 | 例子 |
|---|---|
| 知识未知 | “谁来了？”“故障原因是什么？” |
| 状态差距 | 当前状态与目标状态不同 |
| 行动阻滞 | 原有习惯、流程或计划无法继续 |
| 选择未决 | 多个方案之间尚未决定 |
| 解释竞争 | 同一现象可由多种理论解释 |
| 价值冲突 | 不同主体对“好结果”的判断不一致 |
| 边界未定 | 不清楚哪些因素属于问题 |
| 后果不确定 | 不知道行动会造成什么连锁影响 |

经典 AI 通常把未定性处理为“尚未找到从初始状态到目标状态的路径”。问题逻辑把它处理为“答案空间尚未被确定”。探究传统把它处理为“疑惑、失衡或未定情境”。劣构问题传统则强调：目标、边界、行动集合和评价标准本身都可能未定。

### 3.3 关切与取向

并非一切未定性都是问题。未定性必须对某个主体具有意义。

这里的主体可以是个人、团队、组织、科学共同体、政策参与者、学习者、工程系统的操作者，或任何承担判断与行动的位置。关切可以是求知的、实践的、审美的、伦理的、政治的、经济的或生存性的。

Jonassen 把问题定义为“情境中的未知”加上“求解该未知具有社会、文化或智识价值”。这个判断很关键：没有价值或需要，未知只是未知，不是问题。

Peirce 也有类似直觉：真正的 inquiry 不是把陈述改写成疑问句，而是由真实的 doubt 发动。这里的 doubt 不是空洞怀疑，而是行动习惯受阻、需要重新形成稳定信念的状态。

关切与取向至少完成两件事：

1. 把某个未定性标记为值得处理。
2. 给处理过程一个方向：回答、解释、预测、控制、选择、修复、改变、协调或安顿。

### 3.4 解决判据

问题必须包含某种解决判据。没有解决判据，就无法区分“解决了问题”与“只是继续说话、继续搜索、继续行动”。

解决判据不一定是清晰的数字指标，也不一定是唯一答案。不同传统给出的解决判据不同：

| 传统 | 解决判据 |
|---|---|
| 经典 AI / 规划 | 到达目标状态，通过 goal test，或找到最低代价路径 |
| 问题逻辑 / 形式语义 | 给出真答案、完整答案，或达到足以解决 issue 的信息状态 |
| Peirce | 从真实 doubt 走向稳定 belief |
| Dewey | 未定情境被受控转化为较确定、可继续行动的情境 |
| Collingwood | 答案相对于其问题和前提成为可理解、有根据的回答 |
| 劣构 / 棘手问题 | 形成可辩护、可接受、可行动、能承担后果的暂定方案 |

良构问题的解决判据通常先给定；劣构问题的解决判据往往需要在求解过程中被协商、修正或暂时稳定下来。但即便在劣构问题中，也必须有某种评价依据，否则无法说“这个表述更好”“这个方案更可接受”“这个行动改善了情境”。

## 4. 四条文献线索如何汇合

### 4.1 经典 AI / 认知科学：问题是状态空间中的求路任务

经典 AI 和认知科学的问题求解传统，把问题理解为在 problem space 或 state space 中寻找路径。

最典型的结构是：

```text
Problem = <S, A, T, s0, G, c>
```

| 构件 | 含义 |
|---|---|
| `S` | 状态空间 |
| `A` | 可执行行动或操作 |
| `T` | 状态转移模型 |
| `s0` | 初始状态 |
| `G` | 目标条件或目标测试 |
| `c` | 路径代价或评价函数 |

Newell 和 Simon 的 problem space 传统强调，问题求解发生在由 states 和 operators 构成的表征空间中；具体问题是在该空间中给定初始状态、目标状态和路径约束。Russell 与 Norvig 的经典搜索模型则把 well-defined problem 分解为 initial state、actions、transition model、goal test、path cost。

这条线索的贡献是清楚说明了良构问题的充分结构：只要状态、行动、转移、目标和代价被定义，就可以把问题交给搜索、规划或优化过程。

但它的限制也很明显：它通常假设问题已经被形式化。现实中很多问题的难点恰恰在于：状态空间未定、目标会变、行动后果不确定、代价函数有争议、问题边界需要重新框定。

因此，经典 AI 给出的不是所有问题的充分必要条件，而是良构搜索 / 规划问题的充分必要结构。

### 4.2 Inquiry / Pragmatism / Epistemology：问题是未定情境的规定

Peirce、Dewey、Collingwood 所代表的探究传统，把问题放在实践和认识活动中理解。

在这条线索中，问题不是先摆好的对象，而是从疑惑、失衡、阻滞、冲突或解释需要中发生，并在 inquiry 中被逐步规定。

三位思想家的重心不同：

| 思想家 | 核心图式 |
|---|---|
| Peirce | 从真实 doubt 到稳定 belief |
| Dewey | 从 indeterminate situation 到 determinate situation |
| Collingwood | question-answer complex；陈述只有作为某个问题的答案才有确定意义 |

这条线索补足了经典 AI 的前置盲点：问题不是一开始就有明确状态空间、目标测试和代价函数。很多时候，问题首先表现为一个未定情境；只有经过问题化，才形成“什么相关、什么可问、什么算证据、什么算解决”的结构。

从这条线索看，问题的最小条件不是“有一个问句”，而是：

```text
真实未定情境 + 问题化操作 + 相关材料 + 候选解方向 + 检验或安顿方式。
```

### 4.3 问题逻辑与形式语义：问题是答案或解决条件的结构

问题逻辑、erotetic logic、partition semantics 和 inquisitive semantics 关注的是：一个问题的语义对象是什么？

这条线索给出了从窄到宽的几种模型：

| 模型 | 问题是什么 |
|---|---|
| Hamblin | 可能答案命题的集合 |
| Karttunen | 每个世界中的真答案集合 |
| Groenendijk & Stokhof | 对可能世界空间的互斥穷尽划分 |
| Inquisitive semantics | 足以解决 issue 的信息状态集合 |
| Inferential erotetic logic | 相对于背景前提，答案被保证存在但尚未决定的直接答案空间 |

这条线索的核心贡献是：问题必须有 answerhood 或 resolution profile。也就是说，一个问题至少要规定什么算回答，或什么信息状态算解决。

这也解释了为什么“纯粹困惑”还不是问题。如果没有任何回答空间、解决条件、证据路径或判定方式，就只有混乱或不安，而没有可被处理的问题。

不过，形式语义模型也有覆盖弱点。partition 模型适合有唯一完整答案的问题，但不适合“给我一个可买报纸的地方”这类 mention-some 问题，也不自然适合解释性 why 问题、近似值问题、实践性问题和高度语境化的身份问题。Inquisitive semantics 更一般，因为它把问题理解为解决条件，而不是固定答案集合；但它仍需要语用、解释理论和实践理论补足。

### 4.4 劣构 / 棘手问题：问题是会被求解过程重构的情境性对象

Simon、Rittel & Webber、Jonassen、Checkland、Rosenhead / Mingers 等传统强调：许多现实问题不是良构搜索任务，而是劣构或棘手的问题情境。

在这些情境中，以下构件往往不能预先稳定给定：

| 不稳定构件 | 表现 |
|---|---|
| 边界 | 不清楚哪些因素属于问题 |
| 目标 | 多元、冲突，或会随理解变化 |
| 行动集合 | 无法列出所有可行方案 |
| 约束 | 技术、制度、伦理、资源约束会变化 |
| 评价标准 | 不同主体对“好”有不同判断 |
| 因果后果 | 行动后果不确定、延迟或不可逆 |
| 责任归属 | 谁有权定义问题、谁承担后果本身有争议 |

Rittel 与 Webber 的棘手问题尤其强调：在社会规划中，问题的定义、解释、方案和评价不可分；“问题如何被表述”本身就是问题。Checkland 的 SSM 和 Rosenhead / Mingers 的 PSM 进一步把问题看成通过多视角建模、对话、学习和结构化过程形成的产物。

这条线索说明：最小充分必要条件不能被误解为一张固定字段清单。对劣构问题来说，四个最小构件仍然存在，但它们经常是开放的、争议的、临时的和可修正的。

## 5. 充分必要条件的分层

“什么是构成一个问题的最小充分必要条件”需要分层回答，否则容易把良构问题的条件误当成所有问题的条件。

### 5.1 一般问题的充分必要条件

一般意义上的问题需要且只需要四项：

| 条件 | 必要性 | 充分性 |
|---|---|---|
| 情境域 | 没有情境，就没有相关性、边界和可能变化 | 给出问题发生的场 |
| 未定性 | 没有未定性，就无事可问、可解、可判断 | 给出问题的张力 |
| 关切与取向 | 没有关切，未定性只是事实差异 | 给出问题的意义和方向 |
| 解决判据 | 没有判据，就不能区分解决与未解决 | 给出问题的闭合、安顿或评价方式 |

四者合取，足以构成一个问题；任何一项缺失，都不足以构成问题。

### 5.2 良构问题的充分必要条件

良构问题是一般问题的特例。它要求四项构件都被稳定、明确、可操作地给出。

在经典搜索中，良构问题通常需要：

```text
初始状态 + 行动集合 + 转移模型 + 目标测试 + 路径代价
```

这些条件对于“寻找从起点到目标的低代价行动序列”基本是充分必要的。缺少初始状态，搜索没有起点；缺少行动集合，不知道能做什么；缺少转移模型，无法生成后继状态；缺少目标测试，不知道何时成功；缺少代价函数，则无法定义最优解。

但这是良构搜索问题的条件，不是所有问题的条件。

### 5.3 语义问题的充分必要条件

如果只问“一个问题作为语义对象至少需要什么”，那么最小条件是：

```text
可能性空间 + 回答 / 解决条件
```

在较一般的 inquisitive semantics 中，可以写成：

```text
Q ⊆ P(W)
```

其中 `W` 是可能世界空间，`Q` 是足以解决该 issue 的信息状态集合，并且通常要求非空和下闭：如果某个信息状态已经解决问题，那么更强的信息状态也解决问题。

这适合刻画“什么算回答 / 解决”，但不足以完全解释实践中的问题，因为它通常不直接说明主体为什么关切、情境如何发生、权力如何塑造问题、行动后果如何承担。

### 5.4 劣构问题的充分必要条件

劣构问题不是没有结构，而是问题的关键结构不能在求解前充分稳定。

在一般问题四条件之上，劣构问题还至少包含：

```text
情境域、未定性、关切取向或解决判据中，至少有一个关键部分不能预先稳定给定，并会在探究、建模、争论或行动中被重构。
```

棘手问题是社会性劣构问题的强形式，通常还包含多主体、价值冲突、方案不可穷尽、后果不可完全检验、行动不可完全回滚、责任无法外包等特征。

## 6. 问题、难题、任务、主题、矛盾的区别

| 概念 | 与问题的关系 |
|---|---|
| 疑问句 | 问题的语言表达之一；没有情境和关切时只是句式 |
| 困难 | 可能触发问题；但需被表征为可处理的未定性 |
| 任务 | 已经规定行动目标和完成标准的问题形式 |
| 主题 | 可讨论的对象域；未必包含未定性和解决判据 |
| 矛盾 | 可成为问题的张力来源；但需进入情境和解决取向 |
| 目标 | 可构成问题的一部分；但单独目标不是问题 |
| 解决方案 | 对问题的回应；但方案会反过来改变问题表述 |

这些区分的关键在于：问题具有结构化的未定性。它比主题更尖锐，比困难更有方向，比疑问句更具语境，比任务更原初，比方案更开放。

## 7. 例子

### 7.1 良构问题

“从 Arad 到 Bucharest 找一条最短路径。”

| 构件 | 内容 |
|---|---|
| 情境域 | 罗马尼亚地图上的城市和道路 |
| 未定性 | 尚未知道哪条路径最短 |
| 关切与取向 | 要到达 Bucharest，并优化距离 |
| 解决判据 | 到达目标城市，且总距离最小 |

该问题可以进一步形式化为状态空间搜索：状态是当前城市，行动是沿道路移动，转移模型由道路连接给出，目标测试是是否在 Bucharest，路径代价是距离。

### 7.2 语义问题

“谁参加了会议？”

| 构件 | 内容 |
|---|---|
| 情境域 | 某次会议的参与者可能性空间 |
| 未定性 | 实际参与者集合未确定 |
| 关切与取向 | 说话者需要识别参与者 |
| 解决判据 | 给出足够确定的参与者信息 |

在答案集合模型中，该问题对应若干可能答案命题；在 partition semantics 中，它对应对可能世界的划分；在 inquisitive semantics 中，它对应足以解决“参与者是谁”这一 issue 的信息状态。

### 7.3 探究问题

“为什么这个实验结果与预期不一致？”

| 构件 | 内容 |
|---|---|
| 情境域 | 实验设计、仪器、样本、理论预期和观察结果 |
| 未定性 | 结果与预期冲突，原因未明 |
| 关切与取向 | 研究者需要恢复解释和后续实验方向 |
| 解决判据 | 找到可检验、能解释差异并指导后续操作的假设 |

这里的问题不是一个简单答案集合。它从未定情境中发生，需要事实筛选、假设形成、推理展开和实验检验。

### 7.4 劣构 / 棘手问题

“如何改善城市交通拥堵？”

| 构件 | 内容 |
|---|---|
| 情境域 | 城市空间、居民出行、公共交通、土地使用、财政、环境、政治决策 |
| 未定性 | 拥堵的原因、边界、优先目标和可行方案都不唯一 |
| 关切与取向 | 政府、居民、商家、通勤者、环保组织等都有不同关切 |
| 解决判据 | 通勤效率、公平性、成本、环境影响、政治可行性等多重标准 |

这类问题不能简单转写为一个固定目标函数。定义“拥堵”本身已经包含价值选择：是平均车速、通勤时间、公共交通可达性、碳排放、弱势群体出行权，还是城市生活质量？不同定义会产生不同方案。

## 8. 一个稳健定义

综合四条文献线索，可以给出如下定义：

```text
问题，是主体在某个情境域中遭遇具有意义的未定性，并将其表征为需要回答、判断、行动或改变的对象；它至少包含情境域、未定性、关切取向和解决判据四个构件。
```

这个定义同时保留四个要点：

1. 从经典 AI 保留“问题需要可表征的状态、行动、目标或评价结构”。
2. 从 inquiry 传统保留“问题来自未定情境，并通过问题化被规定出来”。
3. 从问题逻辑保留“问题必须具有 answerhood 或 resolution condition”。
4. 从劣构 / 棘手问题传统保留“问题的边界、目标、评价和方案可能在求解中被重构”。

因此，最小充分必要条件不是某一种固定格式，而是四个功能位置：

```text
情境域：问题在哪里发生？
未定性：什么尚未确定、尚未满足或尚未区分？
关切取向：为什么这值得处理，处理指向什么？
解决判据：什么算回答、安顿、改善或解决？
```

只要这四个位置被某种方式填充，就有一个问题。若它们被稳定、明确、可计算地填充，就是良构问题。若它们部分开放、争议、动态变化，就是劣构问题。若它们涉及多主体价值冲突、不可穷尽方案和不可完全回滚后果，就是棘手问题。
