# MALA

**MALA = More Ask, Less Answer。**

MALA 这个名字表达的是一个核心判断：当问题本身还没有被写对时，更重要的不是急着给出更顺滑的回答，而是先提出更好的问题。

所以，`MALA` 不是“不要回答”，而是“先把问题构造清楚，再进入回答”。它强调的不是反对答案，而是纠正答案出现的位置：先判断当前输入是否已经构成一个真正的问题，是否混了多个层次，真正的未知量到底是什么，然后再求解。

从这个意义上说，MALA 是一个 problem formulation stance，也就是一种“先构造问题，再解决问题”的立场。

## 这个仓库是做什么的

这个仓库用来解释并承载一个“问题构造” skill。

它的核心命题是：

> 回答是在既定问题空间中给出结果，而提问是在构造问题本身的可求解结构。

整套文稿提供这个命题的概念背景、算法背景与数学背景；`SKILL.md` 则是它的操作化版本，用来把尚未成形的原始输入重写成一个真正可回答的问题。

## 如何使用这个 Skill

当输入还只是话题、愿望、态度、模糊目标或混杂请求，而不是一个真正成形的问题时，使用这个 skill。

这个 skill 的工作方式是：

1. 抽取目标、对象、未知、判准、约束、动作、证据与边界；
2. 诊断其中哪些缺失、混杂或错配；
3. 将输入修复为一个可判断、可推进、可更新且最少但足够的问题。
