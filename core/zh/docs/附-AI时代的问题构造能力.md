# AI时代的问题构造能力

如果把前面整组文章放回今天的技术环境里，它会显出一个很直接的现实含义：当答案的生成成本快速下降时，真正稀缺的东西将不再是“会回答”，而是“会构造问题”。

这不是夸张。大模型已经让很多过去成本很高的认知产出变得廉价：摘要、改写、解释、翻译、归纳、类比、甚至相当体面的初步论证，都可以被快速生成。也就是说，回答作为一种压缩结果，其生产能力正在被大规模自动化。

如果我们还停留在旧习惯里，就会产生一种错觉：仿佛因为系统越来越会回答，所以它也越来越会思考。但前面整条链路已经告诉我们，这两者并不是一回事。回答更像 value，像局部估计，像被压缩后的结果缓存；而提问和问题构造，则更像 state abstraction、reward specification、problem formulation。前者是既定结构中的求值，后者是在定义结构本身。

这一区分，在 AI 时代只会变得更重要。

因为一旦回答变便宜，回答本身的边际价值就会下降。一个系统能很快给出一段看似完整的说明，已经不再稀奇；真正稀奇的是，它能否识别这个问题有没有被问坏，能否发现当前目标函数被设歪了，能否指出状态表示里哪些变量只是局部相关，哪些才是稳定机制，能否把一个混杂的需求重新切成可求解的子问题。

换句话说，未来更值钱的能力，不是更快地输出答案，而是更早地发现：我们究竟在解什么题。

这一点在强化学习的比喻里尤其清楚。Value 计算可以越来越强，策略优化可以越来越快，但只要状态抽象错了、奖励函数错了、动作空间漏了，后面的系统就只会更高效地解错题。越会优化，错得越稳定。技术进步不会自动修正问题设定，相反，它会把问题设定的好坏进一步放大。

这就是为什么“问题构造能力”正在变成一种核心能力。它至少包括几件事：

- 判断什么值得被正式求解；
- 指出当前问句里混杂了几个不同层次的问题；
- 明确目标究竟是什么，而不是默认沿用最方便度量的代理指标；
- 识别哪些变量只是表面相关，哪些变量更接近任务的稳定结构；
- 在复杂对象面前，知道如何收缩自由度，而不是只会增加信息。

这些能力过去当然也重要，但在答案稀缺的时代，它们容易被“能给出答案的人”所遮蔽。现在情况变了。既然越来越多系统都能生成一个足够流畅的回答，那么真正拉开差距的，就不会是回答本身，而是问题有没有被切到正确的层次。

这也让“人类应该做什么”这个问题有了一个不那么空的答案。人类未必还需要在每个局部回答上压过机器，但人类仍然需要负责更高层的任务：决定什么是目标，什么是约束，什么是问题，什么只是噪声，什么该被保留，什么该被压掉。也就是说，人类的优势会越来越集中在立题、改题、审题，而不是单纯答题。

如果把这件事说得更尖锐一点，那么可以这样表述：

> 在答案泛滥的时代，真正决定认识边界的，不再是输出能力，而是问题构造能力。

这不是一种对“提问重要”的温和赞美，而是一种越来越现实的分工判断。谁掌握了问题构造，谁就在更高的层面上决定后续所有回答的上限。谁只能消费现成问题、优化现成目标，就只能在既定坐标系里做局部最优。

因此，大模型时代真正值得争夺的，不是“谁能给出更多答案”，而是“谁能更早发现当前问题根本没有被写对”。这才是前面整组讨论在现实中的落点。
