# MALA

**MALA = More Ask, Less Answer.**

MALA is a bilingual repository for a simple claim: when a problem has not yet been written correctly, asking better questions matters more than rushing to produce smoother answers.

The name `MALA` comes from that claim. It does not mean "do not answer." It means that before answering, we often need to decide whether the input is already a real problem, whether several layers have been mixed together, and what the actual unknown is. In that sense, MALA is shorthand for a problem-formulation stance: construct the problem first, then solve it.

## What This Repository Is For

This repository explains and carries a problem formulation skill.

Its central claim is:

> Answers are given inside an already specified problem space, while questioning constructs the solvable structure of the problem itself.

The essays provide the conceptual, algorithmic, and mathematical background for that claim. The skill is its operational form: it takes raw, under-formed input and rewrites it into a question that can actually be answered.

## How To Use The Skill

Use the skill when the input is still a topic, desire, stance, vague objective, or mixed request rather than a properly formed question.

The skill works by:

1. extracting the target, object, unknown, criterion, constraint, action, evidence, and boundary;
2. diagnosing what is missing, mixed together, or mismatched;
3. repairing the formulation into something judgeable, actionable, updatable, and minimally sufficient.
